## CSV 輸出格式規則（依照 SSMS 標準）
1. 基本規則：
   - 欄位間使用逗號分隔
   - 標題列不加引號
   - 預設不使用引號包覆
   - 需要時才使用雙引號包覆
   - 行尾使用 CRLF (\r\n)

2. 引號處理規則：
   - 當欄位包含以下字元時，使用雙引號包覆：
     - 逗號 (,)（不包括全形逗號）
     - 換行符 (LF/CRLF)
     - 雙引號 (")
     - 前後半形空白（包括空格、Tab、換行等）
     - 純半形空白字串
     - 全形空白（如中文全形空格）不會觸發引號包覆
   - 欄位中的雙引號用兩個雙引號表示 ("")
   - 單引號不需特殊處理
   - 連續多個引號時，每個引號都轉為兩個引號

3. 換行處理說明：
   - 當欄位中包含實際換行符時（如 LF 或 CRLF）：
     - SSMS 會保留實際的換行符（不轉換為字面值）
     - 整個欄位會被雙引號包覆
     - 在 CSV 檔案中會呈現為真實的多行文字
     - 這符合 RFC 4180 CSV 標準
     - 注意：這會導致 CSV 檔案的實際行數多於資料列數
   - 字面值的換行符（如字串中的 "\r\n"）：
     - 會直接輸出為字面值，不會轉換為實際換行
     - 如果欄位中同時包含逗號等需要引號的字元，則整個欄位會被引號包覆

4. 值對照表：

  |DB值|CSV輸出格式|是否包覆雙引號|說明|
  |---|---|---|---|
  |DBNull.Value|NULL||NULL值|
  |String.Empty|||空字串|
  |包含逗號的文字|"Hello,World"|是|為了區分該逗號不是分隔符|
  |包含換行的文字|"Line1\nLine2"|是|這裡的 `\n` 會是實際的換行符|
  |包含引號的文字|"Hello""Quote"""|是|雙引號加倍|
  |前後有半形空白|"   Hello   "|是|因前後半形空白|
  |純半形空白|"   "|是||
  |前後有全形空白|　Hello　||全形空白不觸發引號包覆|
  |純全形空白|　　||全形空白不觸發引號包覆|
  |TAB字元|\t||這裡的 `\t` 會是實際的TAB|
  |中間有空白|Hello World||非前後空白|
  |純數值|1234.56||數值|
  |日期時間|2025-03-08 14:28:15.380||日期時間|
  |特殊符號|©®™||特殊符號|
  |中文字|中文測試||中文字|
  |表情符號|🌟🎉||表情符號|
  |控制字元|`SOH`|||
  |零字元|`NUL`|||
